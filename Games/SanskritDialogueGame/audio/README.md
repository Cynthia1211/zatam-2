# Audio files

Put your Sanskrit pronunciation MP3 files in these folders.

## Level 1 - Classroom
`public/audio/level1/`

Expected filenames:
- c1_npc.mp3
- c1a.mp3
- c1b.mp3
- c2a_npc.mp3
- c2a1.mp3
- c2a2.mp3
- c2b_npc.mp3
- c2b1.mp3
- c2b2.mp3
